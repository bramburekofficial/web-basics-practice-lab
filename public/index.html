Jak funguje web

Web je skupina souborů. Prohlížeč si je vyžádá, přečte je a zobrazí stránku.

HTML

HTML dává stránce strukturu: nadpisy, odstavce, odkazy, tlačítka, sekce a obrázky.

CSS

CSS řeší vzhled: layout, barvy, mezery, okraje, hover stavy a mobilní zobrazení.

JavaScript

JavaScript přidává chování: kliknutí na tlačítko, zprávy v Console, API requesty a změny stránky.

Prohlížeč vs server

Prohlížeč běží na tvém počítači. Zobrazuje HTML, aplikuje CSS, spouští JavaScript a přes DevTools ti ukáže, co se stalo.

Server poslouchá requesty a posílá response. V tomto projektu server.js vrací HTML, CSS, JavaScript, obrázky, redirecty, 404 stránku a JSON API odpovědi.

HTTP status codes

Status code ti pomůže pochopit, co se stalo po requestu.

200

OK

Soubor nebo data byla nalezena a úspěšně vrácena.

302

Redirect

Server posílá prohlížeč na jinou URL. Zkus /redirect-demo.

404

Not Found

Prohlížeč požádal o něco, co neexistuje. Zkus chybějící soubor.
