How the web works

A website is a group of files. The browser asks for those files, reads them, and draws the page.

HTML

HTML gives the page structure: headings, paragraphs, links, buttons, sections, and images.

CSS

CSS controls the visual style: layout, colors, spacing, borders, hover states, and mobile behavior.

JavaScript

JavaScript adds behavior: button clicks, browser console messages, API requests, and page updates.

Browser vs Server

The browser runs on your computer. It displays HTML, applies CSS, runs JavaScript, and lets you inspect what happened with DevTools.

The server listens for requests and sends responses. In this project, server.js sends HTML, CSS, JavaScript, images, redirects, 404 pages, and JSON API responses.

HTTP Status Codes

Status codes help you understand what happened after a request.

200

OK

The file or data was found and returned successfully.

302

Redirect

The server sends the browser to another URL. Try /redirect-demo.

404

Not Found

The browser asked for something that does not exist. Try a missing file.
